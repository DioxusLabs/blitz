Core DOM APIs

A consolidated list of the browser DOM APIs used by core Preact, React (react-dom), and the Web Platform Test harness, merged and de-duplicated. A handful of closely related APIs that aren't strictly required by any of the three but make sense to implement alongside their neighbours have been added and marked as extra.

Implementation notes

  • Preact uses only createElementNS (never createElement) and relies heavily on the element[prop] = value fallback guarded by prop in element. It does not use classList, cloneNode, textContent, getAttribute, or the NS attribute variants. preact/hooks touches no element APIs — only requestAnimationFrame, setTimeout, and clearTimeout.
  • React has by far the largest surface: both element-creation calls, a full synthetic event system with the entire native event-name table, the Selection/Range APIs, the three observer APIs, Web Animations + View Transitions, and Trusted Types.
  • WPT harness mostly overlaps with the above but additionally pulls in workers/messaging, fetch, AbortController, and the Node.*_NODE constants. The authored grid test code alone needs only getElementById, element.style, getComputedStyle, and window.opener.
  • The two easiest things to overlook when bootstrapping an engine are Preact's createElementNS-only creation path and the direct element[prop] = value reflected-property fallback.
